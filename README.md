# cursor-cloud

Cloud Agents workspace for Cursor.

## 下载客户端（最新 v0.2.0）

https://github.com/xyiqq/cursor-cloud/releases/tag/v0.2.0

Windows ZIP：https://github.com/xyiqq/cursor-cloud/releases/download/v0.2.0/DeepSeek-Harness-0.2.0-win-x64.zip

解压到 `C:\dsh-desktop\` 后运行 `DeepSeek Harness.exe`。若杀软隔离，在「保护历史记录」选允许。

v0.2.0 起对齐 [ningbainb/deepseek-harness-desktop](https://github.com/ningbainb/deepseek-harness-desktop) 的运行时模型（`ELECTRON_RUN_AS_NODE` + `asarUnpack` + desktop profile），请勿再用 v0.1.x。
