# cursor-cloud

Cloud Agents workspace for Cursor.

## 下载客户端（最新 v0.2.1）

https://github.com/xyiqq/cursor-cloud/releases/tag/v0.2.1

Windows ZIP：https://github.com/xyiqq/cursor-cloud/releases/download/v0.2.1/DeepSeek-Harness-0.2.1-win-x64.zip

解压到 `C:\dsh-desktop\` 后运行 `DeepSeek Harness.exe`。若杀软隔离，在「保护历史记录」选允许。

v0.2.1 内置 [DSH-vison](https://github.com/hisence999/DSH-vison) 图片理解插件（设置 → 图片理解）。
