# 展厅能力规划（Showroom Roadmap）

面向展厅演示：看得见、听得懂、可上手、可控风险。  
关联已有能力：桌面端、图片理解（DSH-vison）、Home Assistant（原生 `ha_*` / MCP）。

---

## 语音要不要在 DSH 里做识别？

**结论：意图调用可以做；ASR（语音→文字）不必塞进 DSH 核心。**

推荐链路：

```text
麦克风 → ASR（外置）→ 文本意图 → DSH（LLM + ha_* / 场景工具）→ HA 执行
                ↑
     可选：浏览器 Web Speech / Whisper 服务 / HA Assist / 手机端
```

| 层级 | 放哪 | 说明 |
|---|---|---|
| 语音识别 ASR | **外置** | 浏览器 Web Speech、本地 Whisper、云 ASR、HA Assist 均可；DSH 只收文本 |
| 意图理解 | **DSH** | 自然语言 → 场景 / `ha_call_service` / 白名单动作 |
| 执行 | **HA** | 场景与实体；危险动作仍拦截 |

为何不优先内置 ASR：

- 展厅环境嘈杂，ASR 选型因场地而异，和 Agent 内核解耦更灵活
- 桌面端打包体积、权限（麦克风）、离线模型都会变重
- DSH 已是「文本进、工具出」；ASR 只是输入前端

后续若要「开箱即用语音」，可在**桌面壳**加可选麦克风按钮（Web Speech 或旁路 Whisper），仍不把 ASR 写进 `@deepseek-ai/dsh` 宿主逻辑。

## 优先级

### P0 — 下一阶段要做（你已点名）

#### 1. 拍照 / 指哪打哪控灯（视觉控家）

- **目标**：拍照或上传展厅画面 → 图片理解描述区域/设备 → 映射到 HA 实体 → 执行开关/调光  
- **依赖**：已有 `dsh-image-vision` + `dsh-homeassistant`  
- **要点**：
  - 实体需有友好名 / 别名 / 区域标签，便于和画面描述对齐
  - 仅白名单域名；执行前可展示「将操作：light.xxx」供确认（展厅可一键确认）
  - 失败时回显「识别到…但未匹配实体」

#### 2. 数字孪生墙同步

- **目标**：大屏平面图 / 示意图上实时反映 HA 实体状态；DSH 操作时高亮对应设备  
- **形态（可选其一或组合）**：
  - A. HA 官方/ Lovelace 平面图投到副屏（最快）
  - B. 桌面端或独立 Web 页：订阅 HA WebSocket `state_changed`，自绘热点图
  - C. DSH 工具调用时推送「焦点实体」事件到孪生页（高亮动画）
- **要点**：展厅网络内网即可；孪生页只读状态 + 接收高亮，写操作仍走 DSH/HA 白名单

#### 3. 语音 → 意图 → 调用（不做重 ASR）

- **目标**：文本（或外置 ASR 结果）触发展厅场景与 HA 动作  
- **要点**：固定口令 + 开放自然语言两档；场景优先于单实体乱调

### P1 — 记录在案、随后做

| 功能 | 简述 |
|---|---|
| **Show Mode 四场景** | 迎宾 / 讲解 / 演示 / 离场；一句口令或大按钮切换；对应 HA Scene |
| **工具调用可视化条** | 大屏显示：意图 → 工具名 → 实体 → 成功/失败（演示可信度） |
| **桌面壳可选麦克风** | 可选 Web Speech / 旁路 Whisper，把文本丢进当前会话（ASR 仍外置） |
| **多 Agent 角色切换** | 导览员 / 家居管家 / 讲解员；切角色时联动灯光或 BGM |
| **观众互动「许愿」** | 扫码或展台按钮；每人限次 + 冷却；仅安全场景 |

### P2 — 有余力再做

| 功能 | 简述 |
|---|---|

| 远程展厅模式 | 公网/隧道演示（需额外安全与网络方案） |

## 建议实施顺序

1. HA 配好四场景 + 实体友好名/区域  
2. **拍照控灯** MVP（识别 → 匹配 → 确认 → 执行）  
3. **孪生墙**（先 Lovelace 投屏，再考虑自研热点图 + 焦点高亮）  
4. 意图口令 / Show Mode 插件化  
5. 可选桌面麦克风入口  
6. 多角色与观众互动

---

## 非目标（展厅阶段明确不做）

- DSH 内置重量级离线 ASR 模型作为默认依赖  
- 7×24 全自动「发现 HA 问题就修」  
- 无白名单的锁 / 报警 / 车库门类自动控制
