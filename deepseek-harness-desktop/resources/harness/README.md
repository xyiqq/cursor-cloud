# Embedded harness runtime (generated)

Run from the project root:

```bash
npm run sync:runtime
```

This installs `@deepseek-ai/dsh` (default `0.1.0-rc.3`, override with `DSH_VERSION`)
into this directory with production dependencies.

`node_modules/` is gitignored. `RUNTIME_VERSION.json` is written by the sync script.
